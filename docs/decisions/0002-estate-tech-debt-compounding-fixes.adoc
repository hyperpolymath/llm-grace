# 2. Source-Level Compounding Fixes for Estate-Wide Tech Debt

Date: 2026-05-17

## Status

Accepted (LIVING — this is the Day-90 retro of the Estate Tech-Debt Recovery
Plan, opened early and backfilled as scheduled items land. Promote to a final
"Accepted, closed" revision at the Day-90 checkpoint.)

## Context

The `hyperpolymath` estate spans 376 repositories. By 2026-05-16 it had
accumulated tech debt that *looked* like ~90 independent per-repo line items
on a 90-day, one-item-per-session recovery plan
(`ESTATE-DEBT-RECOVERY-PLAN.md`).

The initial assumption was that the debt was non-compounding — that each item
had to be paid down individually. Audit against GitHub ground-truth showed the
opposite: a small number of *source-level* fixes each collapse or shrink dozens
of downstream items, because most debt was scaffolded in from a shared template
or generated by a shared automation, and therefore replicated rather than
independently authored.

This ADR records which compounding fixes worked, so the lesson is captured in
the template itself rather than relearned on the next estate-wide cleanup.

## Decision

Front-load source-level fixes ahead of per-repo cleanup, and fold each proven
lesson back into `rsr-template-repo` / `standards` so the debt class cannot
re-accumulate.

Operating rules that proved correct and are now estate policy:

- **Audit claimed state against ground-truth before scheduling dependent
  work.** The 2026-05-16 audit corrected five defects, including stale
  "OPEN/DRAFT vs MERGED" contradictions and four mislabelled affinescript
  issue numbers that would have sent Days 16–19 at closed/unrelated issues.
- **Source-first, then sweep.** Where a canonical repo (standards,
  conative-gating) holds the authoritative copy of a string/pattern, fix it
  there first; the consumer sweep then only mops up replicas.
- **Scope policy must be locked in writing before a bulk sweep runs.** e.g.
  the ReScript sweep preserves `rescript`-named paths and adapters untouched;
  only "use ReScript instead" *guidance* is rewritten. Recorded in the
  `reference_rescript_ecosystem_policy` memory; zig equivalent in
  `reference_vlang_ecosystem_policy`.
- **Destructive items (git history rewrite + force-push) always require
  explicit per-repo confirmation**, even on their scheduled day.

## Consequences

### Positive

- By the Day-25 checkpoint the estate-wide debt *classes* are structurally
  gone; Days 26–90 are per-repo cleanup that shrinks as the sweeps land.
- Recurring GitHub Actions cost bleed eliminated at source (gitbot-fleet#147
  + template `concurrency: cancel-in-progress`) rather than per-repo.
- Fix-once-in-template-propagate-to-all converts an O(repos) cleanup into
  O(source fixes) ≈ 8.
- "Effectively debt-free on the active set" reached around Day 55–65, with
  the tail being optional polish rather than blocking work.

### Negative

- Front-loading concentrates risk and host-resource pressure into the early
  days (e.g. the Day-8 ReScript consumer tail was deferred due to host RAM
  exhaustion making WSL fork-fail — a real throughput limit on bulk sweeps).
- Compounding fixes have hard dependencies (affinescript primitives gate the
  ReScript ports); a blocked source fix stalls a whole tier, not one item.
- Audit overhead is non-trivial but non-optional — skipping it sends
  dependent work at stale/wrong targets.

### Neutral

- The 90-day plan file remains the single source of truth; this ADR is the
  durable lesson extract, not a replacement for it.
- Some items self-resolve ("auto-resolved by Item N") once a compounding fix
  lands — expected and desirable, not plan slippage.
- RSR template updates still need a propagation mechanism to already-existing
  repos (carried forward from ADR-0001's open consequence).

## RSR template changes derived from these lessons

To be applied to `rsr-template-repo` so the debt classes cannot re-accumulate
(backfill links/PRs as each lands):

- [x] CI `concurrency: cancel-in-progress` on all workflow templates
- [x] Clippy panic-gate (warn; ratchet to deny once estate is green — Item 12)
- [x] Artefact `.gitignore` / `.gitattributes` (no committed build output)
- [x] "AffineScript, not ReScript" guidance wording in scaffold docs
- [ ] zig permitted *only* when it is Coq; no V-stub-generation recipes in
      template Justfile/Containerfile/flake (Item 7d)
- [ ] Interface-safety law in scaffold docs: ABI=Idris2 / API+FFI=Zig; every
      boundary gets an Idris2 contract + Zig transaction layer
- [ ] `.scm`→`.a2ml` and `.md`→`.adoc` as the template default formats
- [ ] Mandatory ADR for any banned-runtime / format-drift exception
