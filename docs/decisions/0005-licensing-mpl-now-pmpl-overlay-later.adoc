= ADR-0005: Licensing posture (MPL-2.0 now; PMPL overlay later) + licensing debt
:status: ACCEPTED (with recorded debt)

== Status

*ACCEPTED.* Operative licence is MPL-2.0. Two items of licensing debt
recorded and tracked.

== Context

Scaffolded from `rsr-template-repo`, whose default SPDX is
`PMPL-1.0-or-later` (Palimpsest). Estate licensing rule (owner
Jonathan Jewell):

* Estate canonical default is *PMPL-1.0-or-later* (= Palimpsest-MPL;
  MPL-2.0 is its automatic legal fallback). `llm-grace` is a
  *deliberate owner-ruled MPL-2.0 exception* (not estate drift).
* `007` is excluded (expressly-stated separate licence).
* Anything the owner's son owns, or is repo-admin for, is
  *AGPL-3.0-or-later*.

`llm-grace` is owner-owned, not `007`, not son-owned -> *MPL-2.0*.

PMPL is *not* legally effective standalone: until the governing
council and an established legal code exist, a bare PMPL claim has no
force and falls immediately. PMPL is only ever a *future overlay on
top of* MPL-2.0 — never a replacement, never a present standalone
claim.

== Decision

. Operative licence: *MPL-2.0*. `LICENSE` holds canonical MPL-2.0 text.
. New project files carry `SPDX-License-Identifier: MPL-2.0`.
. No standalone PMPL claim anywhere.

== Licensing debt (recorded, tracked)

* *Debt 1 — relicense (MANUAL ONLY)*: ~199 template files still carry
  `PMPL-1.0-or-later`. Corrected *by the owner, file-by-file, over
  time*. NO automated or bulk sweep, ever (see hard constraint below).
  The `just init` placeholder bootstrap is separate ordinary
  scaffolding and may be done normally; the SPDX relicensing is not.
* *Debt 2 — PMPL overlay migration*: when the council + established
  legal code exist, deliberately move to "MPL-2.0 with PMPL overlay".
  Gated on that external precondition; tracked, not actioned now.

== Hard constraint: licence edits are manual, owner-only

Never automate or bulk-edit licence / SPDX headers in this repo. Every
prior automated attempt across the estate scrambled identifiers and —
critically — rewrote third-party / component licence headers, falsely
attributing other people's licence changes to the owner. Relicensing
is manual, file-by-file, owner-driven. Agents may author *new* files
with correct SPDX and may set this repo's own top-level `LICENSE`, but
must never sweep existing or third-party headers. The relicense debt
is a tracked *manual ledger*, not an automatable task.

== Consequences

Honest, legally-real licence today; aspirational PMPL future is
documented as debt, not silently asserted. Cleanup integrity preserved
by forbidding automation.
