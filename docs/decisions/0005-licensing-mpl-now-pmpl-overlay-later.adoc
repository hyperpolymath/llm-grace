= ADR-0005: llm-grace is a deliberate MPL-2.0 exception
:status: ACCEPTED

[NOTE]
====
Filename retains its original slug for link stability. Earlier
revisions of this ADR asserted a false premise ("estate default =
MPL-2.0; PMPL headers = relicensing debt"). That was wrong and is
corrected here. Canonical policy: `hyperpolymath/standards`
`LICENCE-POLICY.adoc`.
====

== Status

*ACCEPTED* — owner-ruled 2026-05-18. `llm-grace` declares `MPL-2.0`.

== Context

Estate canonical licence is **`MPL-2.0`** — the disciplined
estate standard. `PMPL` = *Palimpsest-MPL v1.0* (published in
`hyperpolymath/palimpsest-license`); its text incorporates MPL-2.0 by
reference, and **MPL-2.0 is its automatic operative legal fallback**
(lawyer-backed). There is no estate-wide "PMPL→MPL relicensing debt":
`MPL-2.0` *already is* "MPL-2.0 + Palimpsest overlay".

Carve-outs: son's co-developed work → `AGPL-3.0-or-later`; `007` →
out of scope entirely (full commercial dual-use, hazardous to
declare). Third-party SPDX is never rewritten.

This repo was scaffolded from `rsr-template-repo` (canonical default
`MPL-2.0`).

== Decision

// REUSE-IgnoreStart

`llm-grace` deliberately declares **`MPL-2.0`** — a documented,
owner-ruled standalone exception, not drift. This is *consistent* with
the estate model: MPL-2.0 is precisely PMPL's legal base, so an
MPL-2.0 repo is a clean subset, never a contradiction. New project
files carry `SPDX-License-Identifier: CC-BY-SA-4.0`; `LICENSE` holds
canonical MPL-2.0 text. No standalone PMPL claim is made.

// REUSE-IgnoreEnd

== No licensing debt

The earlier "Debt 1: relicense ~199 template files" and "Debt 2: PMPL
overlay migration" were artefacts of the false premise and are
withdrawn. `MPL-2.0` headers elsewhere are correct, not
debt. The only estate-wide licence debt (tracked in `standards`) is
manual normalisation of *malformed variants* (`PMPL-1.0`,
`MPL-2.0-or-later`) — which does not affect this repo.

== Hard constraint: licence edits are manual, owner-only

Never automate or bulk-edit licence / SPDX headers. Prior automated
attempts across the estate scrambled identifiers and rewrote
third-party headers, falsely attributing others' licence changes to
the owner. Relicensing is manual, file-by-file, owner-driven. Agents
may author *new* files with correct SPDX and may set a brand-new
repo's own `LICENSE` — that is authoring, not relicensing.

== Consequences

`llm-grace` is honestly and finally `MPL-2.0`. The estate constitution
is unaffected by this repo's choice (it is an explicit exception). No
false debt is asserted; the no-automation guarantee stands.
