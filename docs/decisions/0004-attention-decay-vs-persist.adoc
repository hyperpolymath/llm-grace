= ADR-0004: Attention model — decay vs. persist
:status: ACCEPTED

== Status

*ACCEPTED* — ratified 2026-05-18: persist, motion-gated, no timer.

== Context

The protected session ("the drum", see ADR-0003) is chosen
*dynamic-by-attention*: the heavy+moving session in the terminal the
user most recently submitted a prompt in. `UserPromptSubmit` is the
cheapest available proxy for the user's attention (keystroke-level
focus is not exposed by the harness).

Open question: should "attention" *decay* when the user walks away
(after N minutes idle the drum loses its protected status), or
*persist* until the user submits a prompt in a different terminal?

== Decision

*PERSIST, motion-gated, no timer.* No decay timer is introduced; the
"decay" that is actually needed is supplied for free by the drum being
defined as heavy *and moving* (ADR-0003) — an abandoned terminal that
goes stale stops being the drum because it is no longer moving, not
because a timer fired. Determinism + legibility + zero tuning.

A session the user set working stays the drum even if the
user steps away, until the user explicitly shifts attention by
prompting in another terminal. Rationale: a long-running job the user
launched and walked away from is exactly the work most worth
protecting; decaying its protection mid-run would punish the common
"kick it off and leave it" pattern.

== Consequences / revisit triggers

* If an abandoned terminal that is genuinely stuck (heat, no motion)
  retains protection purely because it was last-touched, the
  heat-vs-motion classifier (ADR-0003) must still demote it — persist
  protects *attention*, not *stalled* work. Confirm the interaction is
  correct under test.
* Revisit if real usage shows stale protection starving newer active
  work.

== Resolution

RATIFIED 2026-05-18 (persist, motion-gated, no timer). The only
residual is an *acceptance test*, not a decision: confirm under the
test-first harness that the ADR-0003 motion classifier genuinely
demotes an abandoned-but-stalled drum (so persist never latches dead
work). Tracked as reframed sub-issue #8.
