recorded as ADRs; the implementation is tracked *test-first* as open
issues and is **not yet live**. This dashboard reflects that reality —
link:../README.adoc[README] and the link:decisions/[ADRs] are the
source of truth. Per link:../AUDIT.adoc[AUDIT.adoc], a bar may only show
progress that is actually backed by merged proofs, tests, or artefacts:
the dashboard must never outrun reality.

== Update protocol

This file is maintained by humans and AI agents. When a workstream lands,
update its bar and cite the PR/issue that backs it. Bars use `█` (filled)
and `░` (empty), ten characters wide, in 10% increments. Keep it honest:
no bar may claim progress that is not backed by merged work.
