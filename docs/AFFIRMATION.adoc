== What this is, and how it works

*What it is.* A dated, signed record of what can be claimed about
*llm-grace* at one exact commit. It makes no promises about the future; the
README covers that.

*What the project is.* Graceful degradation for concurrent LLM and agent
terminals. When system resources run short, sessions back off voluntarily and
in priority order, before the OS out-of-memory killer takes the whole VM down.

*How it stays trustworthy.* Every claim below comes from running the
repository's own `just` recipes in the session that wrote this file. The anchor
names the exact commit. A signed git commit lands the file.

=== The nuance you must not lose

* `just check` says "This is not a release or security certification", and so
  does this file. It covers the structural checks only.
* `just e2e` exits 1 *by design*: the live monitor and hook acceptance suite
  is not implemented (issue #4). The recipe refuses to report a fake success.
* There is no app or daemon binary to install yet (`just run` says so).

=== Known gaps, stated in the repo

* The end-to-end suite (issue #4) and benchmarks are not implemented.

[#outstanding]
=== Outstanding, weak or refuted

* *Ledger tests not run here.* `just test` stops with "unable to find dynamic
  system library 'lmdb'" after the 24 tests above. The ledger tests need the
  LMDB headers and library (`LMDB_PREFIX`), which this machine did not have.
  Their result is *unknown*, not passed.
* *Aspect warnings.* `src/interface/ffi/src/main.zig` lacks an SPDX header.
  The aspect suite flags this as an owner-only licensing review.
* *Red CI at the anchor.* Of 37 check runs on this commit, 25 succeeded, 3 were
  skipped and 9 failed:
  `governance / Actions lockfile verify`,
  `governance / Check Workflow Staleness`,
  `governance / Workflow security linter`, `Hypatia neurosymbolic scan`,
  `openssf-compliance`, `skeleton-drift`, `SonarCloud Code Analysis`,
  `Validate DEED manifests`, `Validate K9 contracts`. None is a required
  check. Issue #96 tracks the pre-existing failures.
